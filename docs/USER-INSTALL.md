# Cara Install ICARUZ (untuk pemain)

Cukup 3 langkah. Tidak perlu install Rust, Node, atau program lain.
Setup hanya sekitar 3 MB, install selesai dalam semenit.

1. Download file `ICARUZ-Setup.exe` dari halaman Releases.
2. Double click file itu. Klik Next sampai Finish.
3. Buka ICARUZ. Pilih folder GTA San Andreas bila diminta. Isi nickname. Pilih server. Tekan Play.

Catatan sekali saja: ICARUZ butuh WebView2 Runtime (komponen Windows).
Kebanyakan Windows 10/11 sudah punya. Kalau app menampilkan peringatan
WebView2 belum ada, install "WebView2 Runtime installer" dari situs
Microsoft, lalu buka ulang ICARUZ.

Jika game belum cocok, ICARUZ tampilkan tombol Perbaiki. Klik itu, setujui perubahan, tunggu selesai.

Tidak ada command line. Tidak ada setting wajib.
