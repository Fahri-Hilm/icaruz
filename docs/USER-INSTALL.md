# Cara Install ICARUZ (untuk pemain)

Pilih salah satu. Tidak perlu install Rust, Node, atau program lain.

## A. Installer (disarankan)
1. Download file `ICARUZ_1.x.x_x64-setup.exe` dari halaman Releases.
2. Double click. Klik Next sampai Finish. Selesai semenit, tanpa admin.
3. Buka ICARUZ. Pilih folder GTA bila diminta. Isi nickname. Pilih server. Tekan Play.

## B. Portable (tanpa install, untuk kentang/flashdisk)
1. Download file `ICARUZ-Portable.zip` dari halaman Releases.
2. Extract ke folder mana saja (termasuk flashdisk).
3. Double click `icaruz.exe`. Selesai, tanpa install.

Catatan sekali saja: ICARUZ butuh WebView2 Runtime (komponen Windows).
Kebanyakan Windows 10/11 sudah punya. Kalau app menampilkan peringatan
WebView2 belum ada, install "WebView2 Runtime installer" dari situs
Microsoft, lalu buka ulang ICARUZ.

Jika game belum cocok, ICARUZ tampilkan tombol Perbaiki. Klik itu, setujui perubahan, tunggu selesai.

Tidak ada command line. Tidak ada setting wajib.
